## Princípios que guiam meus projetos

- O dado deve apoiar decisões, não apenas gerar relatórios.
- A IA deve auxiliar o trabalho humano, não substituí-lo.
- Rastreabilidade e auditoria são fundamentais para confiança.
- Previsibilidade reduz riscos e melhora operações.
- Sistemas aplicados devem resolver problemas reais.
- Segurança, privacidade e governança devem existir desde a concepção.
